# Resume Site Guidance

## Project layout

- `mockups/` contains standalone static HTML resume and portfolio concepts. Open an `index.html` file directly in a browser to preview it.
- `data/career-reference/` is the canonical source for current career facts, project details, timelines, and publication constraints.
- `data/bonus-contributions-reference.md` is the entry point for related career-reference material.

## Content and privacy

- Treat all material in `data/` as confidential working material unless it is explicitly approved for publication.
- Preserve anonymization and publication restrictions recorded in `data/career-reference/sources-and-publication.md`.
- Do not commit presentation files or generated working artifacts; they are excluded by `.gitignore`.

## Changes

- Keep mockups self-contained unless a shared asset structure is deliberately introduced.
- Make focused commits: separate content/reference updates from visual mockup changes.
