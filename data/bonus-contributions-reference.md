## Information architecture

- `profile.md` is the source for reusable professional positioning and headline evidence.
- `projects.md` is the canonical source for project facts. Update project explanations there instead of duplicating them elsewhere.
- `timeline.md` is the source for dates, yearly status, progression, and non-project contributions.
- `sources-and-publication.md` controls confidence, confidentiality, anonymization, and claims that need confirmation.
- The older resume reference remains separate because it represents a different career period and source type.

## Portfolio workflow

1. Choose candidate projects from `sources-and-publication.md`.
2. Pull factual project content from `projects.md`.
3. Confirm dates and progression in `timeline.md`.
4. Use the positioning and metrics in `profile.md`.
5. Anonymize client/internal names and remove protected details.
6. Confirm every item marked as approximate, patent-sensitive, confidential, or needing approval.
